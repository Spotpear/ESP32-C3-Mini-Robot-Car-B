【Standard Version】
Once the device has been flashed, it is ready to use. If you want to use web control, you need to use your phone to connect to the hotspot. A hotspot named “Desktop-Robot” will appear. After connecting, a control interface will automatically pop up. If it does not pop up, use software to visit http://192.168.4.1.

【Voice Version】 (supports manual control and voice control)
Once the device has been flashed, it is ready to use. If you want to use web control, you need to use your phone to connect to the hotspot. A hotspot named “Desktop-Robot” will appear. After connecting, a control interface will automatically pop up. If it does not pop up, use software to visit http://192.168.4.1.

Voice commands:
Wake words: hey robot, hello robot, hey buddy, hi desktop
Action voice commands：
move forward/forward
come here
backward/move back
go away
turn left/go left/to the left
turn right/go right/to the right
stop/do not move/halt
curious mode/be curious/explore/wander around
close curious mode/stop exploring
wiggle/move a bit
dance party
